## 双轨控制机制

### 环境变量配置
```bash
# .env
NEXT_PUBLIC_USE_MOCK_API="true"  # 启用 Mock API
NEXT_PUBLIC_USE_MOCK_API="false" # 禁用 Mock API，使用真实后端
```

### 认证中间件功能
- `getSession()` - 从 Cookie 或 Authorization Header 获取会话
- `requireAuth()` - 验证用户是否已认证
- `generateToken()` - 生成 JWT Token
- `verifyToken()` - 验证 JWT Token
- `setAuthCookie()` - 设置认证 Cookie
- `clearAuthCookie()` - 清除认证 Cookie
- `isMockApiEnabled()` - 检查是否启用 Mock API

### MockServiceWorker 更新
- 根据 `NEXT_PUBLIC_USE_MOCK_API` 决定是否启动 MSW
- 生产环境强制禁用 Mock
- 开发环境显示 Mock API 模式提示
- 暴露 `window.toggleMockApi()` 和 `window.isMockApiEnabled()` 方法

### API 路由集成
- 非 Mock 模式下检查用户认证
- 未登录返回 401 错误
- Mock 模式下跳过认证检查

## 使用方式

### 切换 Mock/真实 API
```bash
# 启用 Mock API (开发环境)
NEXT_PUBLIC_USE_MOCK_API="true"

# 禁用 Mock API，使用真实后端
NEXT_PUBLIC_USE_MOCK_API="false"
```

### 浏览器控制台切换 (开发环境)
```javascript
// 检查当前模式
window.isMockApiEnabled()

// 切换 Mock API
window.toggleMockApi()
```
