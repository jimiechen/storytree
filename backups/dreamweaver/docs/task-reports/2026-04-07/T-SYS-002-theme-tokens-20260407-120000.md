## 经验总结
- **Tailwind v4 主题映射**: v4 中使用 `@theme inline` 时，可以直接将系统颜色映射至原生的 CSS 变量 (如 `var(--background)`)，这极大地简化了基于 CSS 变量的 Light/Dark 切换逻辑。
- **Hydration Mismatch 预防**: 引入 `next-themes` 后，必须在 `<html>` 标签上添加 `suppressHydrationWarning`，防止服务端渲染 HTML 与客户端初次渲染时的 `class="dark"` 不一致报错。
