## 组件特性

### ChatPanel 组件
- **Props Interface**:
  - `projectId: string` - 项目 ID
  - `context?: ChatContext` - 上下文信息 (章节内容、标题等)
  - `compact?: boolean` - 紧凑模式开关

- **快捷操作**:
  ```typescript
  const quickActions = [
    { id: 'continue', label: '/续写', prompt: '请续写以下内容：' },
    { id: 'expand', label: '/扩写', prompt: '请扩写以下内容：' },
    { id: 'rewrite', label: '/改写', prompt: '请改写以下内容：' },
    { id: 'dialogue', label: '/对话', prompt: '请为以下场景编写对话：' },
    { id: 'describe', label: '/描写', prompt: '请描写以下场景：' },
    { id: 'deduce', label: '/推演', prompt: '请推演以下情节发展：' },
  ];
  ```

- **消息样式**:
  - 用户消息: 右对齐，圆角右上角为直角，边框样式
  - AI 消息: 左对齐，圆角左上角为直角，左边框高亮，glass-panel 效果

- **交互功能**:
  - 支持 Shift+Enter 换行
  - 点击快捷操作自动填充输入框
  - 消息自动滚动到最新
  - AI 响应支持 Markdown 渲染
