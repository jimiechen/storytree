## API 端点列表

### 项目管理
- `GET /api/projects` - 获取项目列表
- `POST /api/projects` - 创建新项目
- `GET /api/projects/:id` - 获取单个项目详情
- `PUT /api/projects/:id` - 更新项目
- `DELETE /api/projects/:id` - 删除项目

### 章节管理
- `GET /api/projects/:projectId/chapters` - 获取项目下的章节列表
- `POST /api/projects/:projectId/chapters` - 创建新章节
- `GET /api/chapters/:id` - 获取单个章节详情
- `PUT /api/chapters/:id` - 更新章节
- `DELETE /api/chapters/:id` - 删除章节

## 响应格式

所有 API 返回统一的响应格式，与 MSW Mock 数据格式完全一致：

```typescript
{
  result: {
    code: number;      // 10200 成功, 10400 请求错误, 10404 不存在, 10500 服务器错误
    message: string;   // 响应消息
    data?: any;        // 响应数据
  }
}
```

## 核心功能实现

### 1. 项目字数统计自动更新
- 创建章节时自动增加项目字数
- 更新章节时计算字数差并更新项目
- 删除章节时自动减少项目字数

### 2. 章节自动编号
- 自动获取当前最大章节号
- 新章节默认使用递增编号
- 支持自定义卷号和章节号

### 3. 数据验证
- 项目名称/章节标题必填验证
- 空字符串和纯空格验证
- 项目存在性验证
