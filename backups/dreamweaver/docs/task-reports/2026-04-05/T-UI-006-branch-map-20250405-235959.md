## 组件特性

### BranchNode 数据结构
```typescript
interface BranchNode {
  id: string;
  code: string;
  title: string;
  description: string;
  status: 'main' | 'active' | 'archived' | 'if-line';
  wordCount: number;
  chapters: number;
  position: { x: number; y: number };
  parentId?: string;
}
```

### 分支状态类型
| 状态 | 背景色 | 文字色 | 图标 | 边框样式 |
|------|--------|--------|------|----------|
| main | bg-primary/10 | text-primary | star | border-2 border-primary/40 |
| if-line | bg-secondary/10 | text-secondary | auto_fix_high | border + ring |
| archived | bg-outline-variant/20 | text-on-surface-variant | archive | opacity-60 |
| active | bg-primary/10 | text-primary | circle | border-primary/20 |
