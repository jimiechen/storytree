## 功能实现

### 页面布局
- **顶部导航栏**: 标签导航（角色、地点、物品、传说、概念）+ 搜索框 + 用户头像
- **主内容区**: 页面标题 + 操作按钮 + 3列角色卡片网格
- **右侧面板**: 选中角色的详细信息

### 角色卡片
- **头像**: 姓氏首字，圆形背景
- **状态标签**: 无矛盾（绿色）/ 设定冲突（红色）
- **角色名称**: 大号字体，加粗
- **角色类型**: 主角/配角/反派/龙套
- **信息**: 年龄、出场字数
- **标签云**: 多个标签展示

### 详情面板
- **大头像**: 圆形，带边框
- **基本信息**: 角色类型、年龄、性别、出场字数
- **外貌描述**: 文本展示
- **标签**: 圆角标签
- **编辑按钮**: 编辑角色信息

### 操作按钮
- **手动添加**: 边框按钮
- **AI 自动提取**: 渐变背景，主色调
