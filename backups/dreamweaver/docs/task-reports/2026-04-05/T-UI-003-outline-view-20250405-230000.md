## 功能实现

### 大纲层级展示
- **卷（Volume）**: 带彩色左侧边框的卡片
  - 第一卷: 蓝色边框 (`border-primary`)
  - 第二卷: 橙色边框 (`border-secondary/50`)
  - 第三卷: 绿色边框 (`border-tertiary/50`)
- **章节（Chapter）**: 缩进展示在卷下方
  - 支持展开/折叠
  - 显示章节数量

### 章节状态标签
| 状态 | 标签样式 | 颜色 |
|------|---------|------|
| 草稿 | 灰色背景 | `bg-surface-variant` |
| 写作中 | 蓝色背景 | `bg-primary-container` |
| 定稿 | 绿色背景 | `bg-tertiary-container` |
| 已发布 | 橙色背景 | `bg-secondary-container/20` |

### 点击高亮
- 选中章节显示蓝色边框和背景
- 章节标题变为蓝色加粗
- 显示拖拽指示器图标

### 字数统计
- 显示章节字数（格式: `3.2k`）
- 草稿章节显示 `—`

## 交互功能
- 点击卷标题展开/折叠章节列表
- 点击章节切换到对应编辑器
- 新建章节按钮
- 批量更新按钮
- 导出按钮
