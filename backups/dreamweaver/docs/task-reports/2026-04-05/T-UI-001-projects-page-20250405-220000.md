## 视觉还原要点

### 1. 深色主题
- 背景色: `#111125` (surface)
- 主色调: `#75d1ff` (primary)
- 次要色: `#ffb954` (secondary)
- 强调色: `#83da85` (tertiary)

### 2. 页面布局
- 顶部导航栏: 品牌标识 + 搜索框 + 用户头像
- 左侧: 最近作品列表 (Recent Works)
- 右侧: 快捷入口 + 写作模板
- 底部: 写作洞察统计面板

### 3. 组件样式
- **ProjectCard**: 左侧边框高亮、封面占位、状态标签
- **TemplateCard**: 图标 + 名称 + 英文副标题
- **CreateProjectModal**: 深色弹窗、类型选择网格、渐变按钮

### 4. 交互效果
- 悬停状态: 背景色变化、缩放效果
- 点击反馈: active:scale-95
- 过渡动画: transition-all duration-300
