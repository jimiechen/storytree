## 使用说明

1. **查看原型截图**: 进入任意文件夹，打开 `screen.png`
2. **查看页面规格**: 打开 `prd.md`，包含该页面的详细字段、选项、设计规范
3. **查看可运行代码**: 打开 `code.html`，可在浏览器中直接预览
4. **追溯来源**: 每个 `prd.md` 底部标注了对应的 PRD 章节和 Stitch 提示词节号
