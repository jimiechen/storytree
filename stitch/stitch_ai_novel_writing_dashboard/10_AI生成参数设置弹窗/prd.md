# AI生成参数设置弹窗 - PRD

> 来源: Stitch 提示词 十 | PRD 创作工具-AI生成参数

## 基本信息

| 属性 | 值 |
|------|-----|
| 形态 | Modal 弹窗 |
| 所属模块 | 创作工具 |
| 优先级 | P0 |

## 弹窗结构

### 标题栏

- 标题："生成设置"
- 副标题："自定义AI生成参数"
- 关闭按钮 (×)

### Section 1 - 基础设置

| 字段 | 默认值 | 范围 |
|------|--------|------|
| 生成数量 | 10 章 | 5-20 |
| 目标字数 | 3000 字 | 1000-10000 |
| 字数容差 | ±300 字 | - |
| AI模型 | 豆包模型 ▼ | 豆包/文心/通义 |

### Section 2 - 上下文参考

- **参考章节数**: 下拉 "3 章"（范围：1-10）
- **复选框网格（2列）**:

| 选项 | 默认 | 说明 |
|------|------|------|
| ☑ 大纲和细纲 | 必选(禁用) | 始终启用 |
| ☑ 已有正文摘要 | 可选 | - |
| ☑ 主角状态追踪 | 可选 | - |
| ☑ 角色关系 | 可选 | - |
| ☑ 技能和道具状态 | 可选 | - |
| ☐ 重要事件 | 未选 | - |

### Section 3 - 包含设定（可折叠）

- ☑ 角色设定
- ☑ 技能/法宝
- ☑ 物品/道具
- ☑ 地点场景
- ☑ 已有剧情线

### 底部按钮

- "恢复默认"（文本链接，左侧）
- "取消"（灰色描边，右侧）
- "开始生成"（紫粉渐变，右侧，主按钮）

## 设计规范

- 有组织的表单分区
- 清晰分组
- 直观控件
- 中文文本
