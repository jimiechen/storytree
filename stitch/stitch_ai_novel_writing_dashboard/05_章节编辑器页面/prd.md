# 章节编辑器页面 - PRD

> 来源: Stitch 提示词 五 | PRD 创作工具-章节编辑

## 基本信息

| 属性 | 值 |
|------|-----|
| 页面路径 | 章节编辑视图 |
| 所属模块 | 创作工具 |
| 优先级 | P0 |

## 布局结构

### 顶部工具栏

- 返回箭头 + "第X章 XXXXX" 标题
- 字数统计 "共 X,XXX 字"
- 操作按钮：历史版本 | 备注 | AI续写 | 保存 (Ctrl+S)

### 主编辑区

- 大型文本编辑区，中文小说正文内容
- 排版整洁，舒适的阅读行高
- 光标闪烁于文本末尾
- 选中文本高亮

### 右侧面板（~280px）

**章节信息** 区：

| 字段 | 示例值 |
|------|--------|
| 状态 | 已完成（绿色徽章） |
| 创建时间 | 2026-05-20 14:30 |
| 最后修改 | 2026-05-24 09:15 |

**AI提取信息** 区：

| 字段 | 示例值 |
|------|--------|
| 章节摘要 | 主角参加门派比武大会... |
| 新角色 | 林清风（对手） |
| 主角状态 | 位置：比武场 \| 情绪：紧张 \| 实力：金丹期 |
| 获得道具 | 无 |
| 重要事件 | 主角获胜，获得进入秘境资格 |

- "重新提取信息"按钮（小型，描边）

## 设计规范

- 无干扰写作环境
- 浅色背景
- 舒适阅读体验
- 中文文本
