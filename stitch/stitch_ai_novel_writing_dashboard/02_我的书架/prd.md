## 基本信息

| 属性 | 值 |
|------|-----|
| 页面路径 | `/center` |
| 所属模块 | 项目管理 |
| 截图文件 | 03_我的书架 / 12_我的书架_更新后 |
| 优先级 | P0 |

## 页面元素

### 顶部导航栏

- 汉堡菜单图标（≡）左侧
- 紫色书本图标 + "我的书架" 标题 + "N本" 数量徽章（紫色）
- 刷新图标右侧

### 搜索栏

- 全宽搜索框，placeholder "搜索小说..."，右侧帮助图标(?)

### 工具栏行（彩色图标按钮）

- 紫色闪电（快速操作）
- 橙色网格图标（模板）
- 蓝色文档图标
- 绿色勾选图标
- 白色"新建"按钮 + 加号图标
- 紫色闪光图标
- 两个带数字的文档图标

### 主内容区 - 项目卡片网格（2列）

每张卡片显示：
- 书籍封面占位符（渐变色矩形）
- 书名（如"星辰变"）
- 类型标签（如"玄幻"）
- 章节统计 "共 X 章"
- 字数统计 "共 X,XXX 字"
- 最后编辑时间 "最后编辑：X小时前"
- 悬停覆盖层带编辑/删除按钮

### 右下角浮动组件

- "今日已签到" + 火焰图标 + "X天" 连续签到
- "成就 X/98" + 星星图标
- "活动 点击查看" + 礼物图标
- 统计: "XXX,XXX,XXX 字" 和 "XXX 在线"

### 空状态设计

- 空状态图标：书本图标
- 标题："书架空空如也"
- 描述："创建你的第一部小说..."
- 创建按钮：简易创作(推荐) / 创建新项目 / 25道题引导

## 功能入口清单

| 按钮 | 功能 |
|------|------|
| 更新 | 查看更新内容 |

| 短篇创作 | 创建短篇项目 |
| 签约审核 | 审核签约内容 |
| 新建 | 新建项目下拉菜单 |
| AI工具箱 | AI工具集合 |
| 回收站 | 已删除项目 |

## 设计规范

- 背景：浅灰色 (#f5f5f5)
- 卡片：白色卡片 + 轻微阴影
- 强调色：紫色系
- 圆角：8-12px
- 中文文本
