# 创建新项目弹窗 - PRD

> 来源: AI小说创作助手 PRD 3.4 | Stitch 提示词 三

## 基本信息

| 属性 | 值 |
|------|-----|
| 页面路径 | `/center`（弹窗形式） |
| 所属模块 | 项目管理 |
| 截图文件 | 04_创建新项目_基本信息 |
| 优先级 | P0 |

## 弹窗结构

### 弹窗标题栏

- 标题："创建新项目"
- 关闭按钮 (×)

### Tab 切换（顶部）

| Tab | 说明 |
|-----|------|
| 简易创作 | 快速创建模式（推荐标签） |
| 创建新项目 | 完整创建流程 |

### 表单字段 - 基本信息

| 字段 | 类型 | 验证规则 |
|------|------|---------|
| 书名 * | input | 必填，placeholder "给你的小说起个名字" |
| 类型 * | dropdown | 必填，选项：玄幻/都市/穿越/科幻/仙侠/悬疑/其他 |
| 简介 | textarea | placeholder "简单描述小说要讲什么故事..."（3-4行） |

### 主角设定区域

| 字段 | 类型 | 说明 |
|------|------|------|
| 姓名 | input | 主角名字输入 |
| 性别 | radio | 男 / 女 |
| 年龄 | input | 数字字段 |
| 性格 | textarea | placeholder "描述主角的性格特点..." |

### 自定义设定

- textarea: placeholder "添加修仙体系、科技设定等自定义内容..."

### 底部按钮

- "取消"（灰色描边）
- "创建"（紫粉渐变，主按钮）

## 目标读者选项

| 选项 | 说明 |
|------|------|
| 大众（通用） | 通用读者群体 |
| 男频（热血、升级、爽文） | 男性向爽文 |
| 女频（言情、情感、细腻） | 女性向言情 |

## 写作风格选项

默认 / 诙谐幽默 / 人性黑暗 / 杀伐果断 / 文学性强 / 快节奏 / 慢节奏 / 悬疑 / 热血 / 轻松 / 虐心 / 自定义

## 故事主题选项

默认 / 复仇 / 成长 / 爱情 / 冒险 / 救赎 / 权力 / 友情 / 生存 / 探索 / 竞争 / 家庭 / 自定义

## 设计规范

- 白色模态框 + 圆角
- 遮罩背景
- 清晰表单布局
- 中文文本
