## 引导首页 (/novel-guide)

### 头部栏

- 关闭按钮 (×) 右侧
- "返回管理中心"链接左侧 + 返回箭标

### 主内容

- 大标题："✨ 25道题创建引导" + 闪光emoji
- 副标题："通过25道精心设计的题目，帮你构建完整的小说框架"

- "新建引导项目"按钮（大号，紫粉渐变，+ 图标）

## 新建引导项目 (/novel-guide/new)

### 头部

- 关闭按钮 (×)
- "返回列表"链接 + 返回箭标
- 标题："新建引导项目"

### 表单卡片

| 字段 | 类型 | 要求 |
|------|------|------|
| 小说标题 * | input | 必填，placeholder "给你的小说起个名字"，提示 "好的标题能吸引读者" |
| 小说类型 * | dropdown | 必填，选项：玄幻/都市/穿越/科幻/仙侠/悬疑/言情/其他 |
| 目标字数 | dropdown | 可选，见下方选项 |

### 目标字数选项

| 选项 | 说明 |
|------|------|
| 10万字（短篇） | 适合新手练笔 |
| 30万字（中篇） | 标准网文长度 |
| 50万字（中长篇） | 深度故事 |
| 100万字（长篇） | 宏大世界观 |
| 200万字以上（超长篇） | 史诗巨作 |

### 按钮

- "取消"（灰色描边）
- "开始创建"（紫粉渐变，未填写必填项时禁用）

## 引导问答流程示例（Q1）

- 进度："创建你的专属小说" + 进度条 "1/25"
- 问题编号徽章："Q1"
- 问题："你想写什么类型的小说？"
- 副标题："选择最接近你想法的类型，后续可随时调整。"
- 选项卡片网格（2x3）：🐉玄幻修仙 / 🏙️现代都市 / ⏰穿越重生 / 🚀科幻未来 / 🔍悬疑推理 / 💕言情甜宠
- 底部导航："上一步"(禁用) / "下一步"(紫粉渐变) / "跳过引导"
