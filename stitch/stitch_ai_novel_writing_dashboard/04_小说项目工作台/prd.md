# 小说项目工作台 - PRD

> 来源: Stitch 提示词 四（核心编辑页面）

## 基本信息

| 属性 | 值 |
|------|-----|
| 页面路径 | 小说编辑工作台 |
| 所属模块 | 创作工具 - 核心 |
| 优先级 | P0 |
| 对应PRD章节 | 大纲生成(3.x) / 细纲生成 / 正文生成 / 章节编辑 |

## 三栏布局

### 左侧面板（侧边栏，~250px宽）

**Tab 切换器**: 大纲 | 细纲 | 章节

大纲列表项：
- 章节编号 "第X章"
- 章节标题
- 选择复选框
- 展开箭头 (▶) 子项
- 星标图标（标记重要）

底部按钮：
- "AI生成大纲"（紫色渐变）
- "生成细纲"（描边样式）

### 中间面板（主内容区）

**顶部栏**:
- 当前章节："第X章 XXXXX"
- 内容区域：大纲文本或章节正文
- AI生成进度条（如正在生成）：
  - 进度："正在生成第X章... XX%"
  - 实时预览文本出现中
  - "暂停"按钮
  - "...(后续内容待生成)..."

### 右侧面板（设置与信息，~300px宽）

**生成设置** 区域：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 目标字数 | 3000 | +/- 按钮调节 |
| 字数容差 | ±300 | |
| 参考章节数 | 3 | 下拉选择 |
| AI模型 | 豆包 | 下拉选择 |

**上下文参考** 复选框：

- ☑ 大纲和细纲（必选）
- ☑ 已有正文摘要
- ☑ 主角状态追踪
- ☑ 角色关系
- ☑ 技能和道具状态
- ☐ 重要事件

**操作按钮**：
- "开始生成"（紫粉渐变，全宽）
- "批量生成"（描边样式）

## 设计规范

- 专业写作工具美学
- 清晰面板分隔线
- 紫色强调色
- 中文文本
