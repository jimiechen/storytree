### **图里的现象——gizmo 不在长方体中心、还有一组小蓝/红方块漂在两者之间——本质是 box mesh 的"几何中心 ≠ mesh.position"，以及上一轮没真正拆出独立 box-manager 导致仍有残留旧 mesh。先用一个统一的 `SceneObjectManager` 抽象把圆柱、长方体、未来的角色/道具/相机/灯统一掉，再用"标准化 mesh 中心 + userData.kind 分发"一次性解决 gizmo 偏移、方阵整体操作和未来加新物体不再重新调试三个问题。**

下面分三块：先解释你看到的现象到底是什么，再给出抽象方案，最后给 Trae 的执行 Prompt。

---

## **一、先看懂图里发生了什么**

放大看图能定位到三件事，三件事是叠加的：

```text
1. 长方体右侧 gizmo 中心在长方体"上方左侧"，不在长方体几何中心
   → 长方体 mesh 的 position 不是它的几何中心，多半是底面中心或角点
   → TransformControls 永远绑在 mesh.position，所以 gizmo 跟着 position 走，不跟着"看上去的几何中心"走

2. 两者之间漂着一对小红蓝方块（看起来像两个未对齐的迷你 box）
   → 这是上一轮三数组重构没清理干净的旧 mesh 残留
   → 大概率是旧 cylinder-manager.boxGroup 还在场景中加 mesh
   → 同时新 boxes 数组又通过新路径加了一份
   → 一对 box 实例叠加 = 双份渲染

3. 整体感觉"方阵分散、各动各的"
   → 上一轮我们刻意取消了方阵整体操作（多 box reparent 到 group）
   → 但你需求里希望"方阵作为一个整体"，目前实现是"每个 box 独立"
   → 这不是 bug，是产品定义问题——下面会重新定义
```

也就是说，你眼前的问题是 **几何中心偏移 + 旧残留 mesh + 方阵语义缺失** 三件事撞在一起。光看 gizmo 位置不能定位完整，三件都要修。

## **二、根本解药：抽象一个 SceneObjectManager**

你提的方向是对的——**不要再做 cylinder-manager、box-manager、light-manager 三份代码**。三份代码意味着每加一种物体（角色、道具、相机、灯、镜头标记）就要新建一个 manager、改一遍 InfoPanel、改一遍 Effect、改一遍 TransformControls 分发。这是上一轮我们一直没彻底掉的债。

正确做法是建立一个通用对象抽象层。

### **2.1 抽象层结构**

```text
SceneObject（数据）
  ├─ id
  ├─ kind: 'cylinder' | 'box' | 'light' | 'character' | 'prop' | 'camera' | ...
  ├─ position / rotation / scale
  ├─ groupId?            ← 方阵 / 编组用
  ├─ shape: ShapeSpec    ← 决定如何生成 geometry
  ├─ material: MaterialSpec
  └─ extras: kind 特有属性（intensity / range / focalLength / …）

ShapeSpec（统一外形描述）
  ├─ kind: 'cylinder' | 'box' | 'cone' | 'sphere' | 'gltf' | 'lineCone' | ...
  └─ params: 该 shape 需要的参数

SceneObjectManager（统一渲染层）
  ├─ group: THREE.Group
  ├─ entries: Signal<SceneObjectEntry[]>
  ├─ update(objects, selectedId, theme)
  ├─ raycast(raycaster)
  ├─ findById(id)
  ├─ findByGroupId(groupId)          ← 方阵支持
  └─ dispose()

ShapeFactory（注册式工厂）
  ├─ register(shapeKind, builder)
  ├─ build(spec) → THREE.Object3D
  └─ 内置：cylinder / box / cone(lineDashed) / sphere

GroupController（方阵）
  ├─ wrap(groupId, mesh[])  → 把 N 个 mesh 临时 parent 到一个 helper Group 做整体变换
  ├─ unwrap(groupId)         → 解组时把 mesh 还原到 SceneObjectManager.group，写回各自 world transform
  └─ TransformControls 绑定到 helper Group 而不是单个 mesh
```

### **2.2 这套抽象解决了什么**

```text
① 加新物体只需要：
   - 在 SceneObject.kind 里加一个字符串
   - 在 ShapeFactory 注册一个 builder
   - 不改 manager / InfoPanel / Effect / TransformControls 分发
   
② gizmo 偏移问题：
   - 所有 ShapeBuilder 必须遵守"mesh 的 position 永远 = 几何中心"
   - cylinder.geometry 默认中心已在原点，OK
   - box.geometry 默认中心已在原点，但如果有人在 build 时 translate 了底面对齐，必须改回
   - lineCone 需要主动 translate(0, -range/2, 0) 让"光源原点 = 锥尖"，这是有意为之，不冲突
   
③ 方阵：
   - groupId 写入 SceneObject 数据
   - 选中 groupId 任一成员 = 视为选中整组
   - GroupController.wrap 临时编组做整体变换
   - 拖拽结束后 unwrap，把变换写回每个 SceneObject

④ 残留 mesh：
   - 只有一个 SceneObjectManager，update() 内部 Map<id, Entry> 增量 diff
   - 没有 cylinder-manager 和 box-manager 并存的可能
   - 残留 mesh 自然消失
```

### **2.4 ShapeFactory 注册示例**

```ts
// novel-3d/shape-factory.ts
type ShapeBuilder = (spec: ShapeSpec, mat: MaterialSpec) => THREE.Object3D;

const registry = new Map<ShapeKind, ShapeBuilder>();

export const ShapeFactory = {
  register(kind: ShapeKind, builder: ShapeBuilder) {
    registry.set(kind, builder);
  },
  build(spec: ShapeSpec, mat: MaterialSpec): THREE.Object3D {
    const b = registry.get(spec.kind);
    if (!b) throw new Error(`No shape builder for `);
    const obj = b(spec, mat);
    // 强约束：obj.position 永远 = 几何中心（原点）
    // builder 内部如有偏移必须用 geometry.translate 而非 mesh.position
    return obj;
  },
};

// 注册 cylinder
ShapeFactory.register('cylinder', (spec, mat) => {
  const r = (spec.params.radius as number) ?? 0.5;
  const h = (spec.params.height as number) ?? 1.5;
  const geom = new THREE.CylinderGeometry(r, r, h, 32);
  // 不要再 translate，几何中心已在原点
  const material = buildStdMaterial(mat);
  const mesh = new THREE.Mesh(geom, material);
  return mesh;
});

// 注册 box
ShapeFactory.register('box', (spec, mat) => {
  const w = (spec.params.width as number) ?? 1;
  const h = (spec.params.height as number) ?? 1;
  const d = (spec.params.depth as number) ?? 1;
  const geom = new THREE.BoxGeometry(w, h, d);
  // 几何中心已在原点，不 translate
  const mesh = new THREE.Mesh(geom, buildStdMaterial(mat));
  return mesh;
});

// 注册 lineCone（光源虚线）
ShapeFactory.register('lineCone', (spec, mat) => {
  const range = (spec.params.range as number) ?? 3;
  const angleDeg = (spec.params.angleDeg as number) ?? 30;
  const radius = Math.tan((angleDeg * Math.PI) / 180) * range;
  const cone = new THREE.ConeGeometry(radius, range, 24, 1, true);
  // 这里有意 translate：让"光源原点 = 锥尖"
  cone.translate(0, -range / 2, 0);
  const edges = new THREE.EdgesGeometry(cone);
  const lineMat = new THREE.LineDashedMaterial({
    color: new THREE.Color(mat.color),
    dashSize: 0.08, gapSize: 0.05,
    transparent: true,
    opacity: mat.opacity ?? 0.7,
  });
  const line = new THREE.LineSegments(edges, lineMat);
  line.computeLineDistances();
  // 套一个 root group 容纳光源点小球
  const root = new THREE.Group();
  root.add(line);
  const bulb = new THREE.Mesh(
    new THREE.SphereGeometry(0.08, 12, 8),
    new THREE.MeshBasicMaterial({ color: mat.color })
  );
  root.add(bulb);
  return root;
});
```

### **2.5 SceneObjectManager 关键方法**

```ts
// novel-3d/scene-object-manager.ts
export interface SceneObjectEntry {
  id: string;
  obj: THREE.Object3D;
  kind: SceneObject['kind'];
  groupId?: string;
}

export function createSceneObjectManager() {
  const group = new THREE.Group();
  group.name = 'SceneObjects';
  const [entries, setEntries] = createSignal<SceneObjectEntry[]>([]);
  const map = new Map<string, SceneObjectEntry>();

  const update = (objects: SceneObject[], selectedId?: string) => {
    const incoming = new Set(objects.map(o => o.id));

    // 删除
    for (const [id, e] of map) {
      if (!incoming.has(id)) {
        group.remove(e.obj);
        disposeObject(e.obj);
        map.delete(id);
      }
    }

    // 新增 / 更新
    for (const o of objects) {
      let entry = map.get(o.id);
      const isNew = !entry;

      if (!entry) {
        const obj = ShapeFactory.build(o.shape, o.material);
        obj.userData.id = o.id;
        obj.userData.kind = o.kind;
        obj.userData.groupId = o.groupId;
        group.add(obj);
        entry = { id: o.id, obj, kind: o.kind, groupId: o.groupId };
        map.set(o.id, entry);
      }

      // 选中高亮（统一通过 material override）
      applySelectionStyle(entry.obj, o, o.id === selectedId);

      // 位置 / 旋转 / 缩放 epsilon 保护
      if (isNew || diffTransform(entry.obj, o) > 1e-4) {
        entry.obj.position.set(o.position.x, o.position.y, o.position.z);
        entry.obj.rotation.set(o.rotation.x, o.rotation.y, o.rotation.z);
        entry.obj.scale.set(o.scale.x, o.scale.y, o.scale.z);
      }

      // groupId 变化更新 userData
      entry.obj.userData.groupId = o.groupId;
      entry.groupId = o.groupId;
    }

    const next: SceneObjectEntry[] = [];
    for (const o of objects) {
      const e = map.get(o.id);
      if (e) next.push(e);
    }
    setEntries(next);
  };

  const findById = (id: string) => entries().find(e => e.id === id);
  const findByGroupId = (gid: string) => entries().filter(e => e.groupId === gid);

  const raycast = (raycaster: THREE.Raycaster) => {
    const candidates: THREE.Object3D[] = [];
    for (const e of map.values()) candidates.push(e.obj);
    const hits = raycaster.intersectObjects(candidates, true);
    for (const h of hits) {
      // 向上回溯找最近的有 userData.id 的祖先
      let cur: THREE.Object3D | null = h.object;
      while (cur && !cur.userData?.id) cur = cur.parent;
      if (cur && cur.userData?.id) return findById(cur.userData.id as string);
    }
    return undefined;
  };

  const dispose = () => {
    for (const [, e] of map) disposeObject(e.obj);
    map.clear();
    setEntries([]);
    group.clear();
  };

  return { group, entries, update, raycast, findById, findByGroupId, dispose };
}
```

### **2.6 方阵：GroupController**

```ts
// novel-3d/group-controller.ts
export function createGroupController(scene: THREE.Scene, manager: SceneObjectManager) {
  const helpers = new Map<string, THREE.Group>();  // groupId → helper

  const wrap = (groupId: string): THREE.Group | null => {
    const members = manager.findByGroupId(groupId);
    if (members.length === 0) return null;

    let helper = helpers.get(groupId);
    if (!helper) {
      helper = new THREE.Group();
      helper.name = `group-helper-`;
      scene.add(helper);
      helpers.set(groupId, helper);
    }

    // 计算重心
    const center = new THREE.Vector3();
    members.forEach(m => center.add(m.obj.position));
    center.divideScalar(members.length);
    helper.position.copy(center);
    helper.rotation.set(0, 0, 0);
    helper.scale.set(1, 1, 1);

    // 把成员 attach 到 helper（保留世界变换）
    for (const m of members) {
      helper.attach(m.obj);   // THREE.Group.attach 会保持世界变换
    }
    return helper;
  };

  const unwrap = (groupId: string, store: Shot3DStore) => {
    const helper = helpers.get(groupId);
    if (!helper) return;
    const members = manager.findByGroupId(groupId);
    for (const m of members) {
      manager.group.attach(m.obj);  // 还原到 manager.group，保留世界变换
      // 写回 store
      store.updateObject(m.id, {
        position: { x: m.obj.position.x, y: m.obj.position.y, z: m.obj.position.z },
        rotation: { x: m.obj.rotation.x, y: m.obj.rotation.y, z: m.obj.rotation.z },
        scale:    { x: m.obj.scale.x,    y: m.obj.scale.y,    z: m.obj.scale.z    },
      });
    }
    scene.remove(helper);
    helpers.delete(groupId);
  };

  return { wrap, unwrap };
}
```

**关键点**：使用 `Group.attach()` 而不是 `Group.add()`，前者会保留世界变换，后者会让子对象瞬移到 helper 的本地坐标。这是方阵不闪现的关键。

### **2.7 方阵选中策略**

选中行为升级为：

```text
点击某个 mesh
  ↓
拿到 SceneObject
  ↓
if (object.groupId) {
  // 方阵成员：选中整组
  groupCtrl.wrap(groupId) → helper
  transformCtx.attach(helper)
} else {
  // 单体：选中自己
  transformCtx.attach(object.obj)
}
```

拖拽结束后：

```text
if (当前 attach 的是 helper) {
  groupCtrl.unwrap(groupId, store)
}
```

这样从用户视角看：

```text
- 选中方阵任意一个长方体 = 选中整组
- gizmo 出现在方阵重心
- 拖动整组移动 / 整组旋转 / 整组缩放
- 松手后每个长方体的 position 单独写回 store
- 单独想动某一个 → 把它从方阵移出（store 里 groupId = undefined）
```
