### **三、需要修正：ViewModel 示例里的换行 split 写法**

文档里的示例有一处需要 Trae 注意：

```ts
return content.split('

').filter(Boolean);
```

这里在 Markdown 转换后显示成了断行，实际代码里应该写成：

```ts
return content
  .split(/\n\s*\n/)
  .map((paragraph) => paragraph.trim())
  .filter(Boolean);
```

```text
\n \n
\r\n\r\n
```
