### **如果需要真正的 3D 视角、旋转、平移、方位轴和相机，那就不应再用 SVG 简化画布，而应改成“Solid.js + Three.js 的轻量 3D 构图视口”。**

你现在的需求已经从“2.5D 构图参考图”升级为 **3D 构图编辑器 MVP**：需要像 Godot 一样有透视相机、视角旋转、平移、缩放、方位轴、网格地面、相机对象、圆柱体方阵、对象拖拽/移动。这个阶段可以引入 Three.js，但仍然不做真实游戏渲染、不做 PBR、不做复杂材质，只做低成本 3D 布局和拍摄角度控制，用于生成图像模型的参考图和相机参数。

## **一、方案调整结论**

原方案：

```text
Solid + SVG + Store
生成 2.5D 拍摄角度参考图
```

现在应改为：

```text
Solid.js + Three.js + Camera Controls + Transform Controls
实现轻量 3D 构图视口
```

新的产品定位是：

```text
Prompt → 3D 圆柱体方阵 → Godot 风格视口旋转/移动 → 相机取景 → 导出参考图 + 相机参数 + Prompt
```

它不是完整 Godot，也不是游戏引擎，而是一个：

```text
AI 图像生成前的 3D 构图导演台
```

## **二、为什么必须改用 Three.js**

因为你明确需要：

```text
3D 视角
旋转视角
平移视角
缩放视角
有方位
有相机
圆柱体真实空间排列
```

这些能力用 SVG 可以模拟，但会很快变得不自然。SVG 适合做构图草图，不适合做真正的 3D 视口。

Three.js 则天然支持：

| 能力 | Three.js 支持情况 |
|---|---:|
| PerspectiveCamera 透视相机 | 支持 |
| OrthographicCamera 正交相机 | 支持 |
| OrbitControls 旋转/平移/缩放 | 支持 |
| TransformControls 移动/旋转/缩放对象 | 支持 |
| GridHelper 地面网格 | 支持 |
| AxesHelper 方位轴 | 支持 |
| CylinderGeometry 圆柱体 | 支持 |
| CameraHelper 相机锥体显示 | 支持 |
| 导出 canvas 截图 | 支持 |
| 低成本材质和灯光 | 支持 |

所以现在应明确：**MVP 可以使用 Three.js，但只作为 3D 构图工具，不做真实渲染器。**

## **八、Three.js 关键实现方式**

### **1. 初始化 Scene**

```typescript
const scene = new THREE.Scene()
scene.background = new THREE.Color('#1e1f22')

const camera = new THREE.PerspectiveCamera(
  60,
  width / height,
  0.1,
  1000,
)

camera.position.set(-6, 3, 8)

const renderer = new THREE.WebGLRenderer({
  antialias: true,
  preserveDrawingBuffer: true,
})

renderer.setSize(width, height)
```

### **2. OrbitControls**

```typescript
const controls = new OrbitControls(camera, renderer.domElement)
controls.target.set(0, 1.5, 0)
controls.enableDamping = true
controls.dampingFactor = 0.08
controls.enablePan = true
controls.enableZoom = true
controls.enableRotate = true
```

### **3. Grid 和方位轴**

```typescript
const grid = new THREE.GridHelper(30, 30, '#3d6cff', '#2a2a2a')
scene.add(grid)

const axes = new THREE.AxesHelper(3)
scene.add(axes)
```

### **4. 圆柱体**

```typescript
const geometry = new THREE.CylinderGeometry(radius, radius, height, 48)

const material = new THREE.MeshStandardMaterial({
  color,
  roughness: 0.5,
  metalness: 0.2,
})

const cylinder = new THREE.Mesh(geometry, material)
cylinder.position.set(x, height / 2, z)
scene.add(cylinder)
```

### **5. Hero 圆柱发光**

MVP 可以先用 emissive：

```typescript
const heroMaterial = new THREE.MeshStandardMaterial({
  color: '#ff9f1c',
  emissive: '#ff7a00',
  emissiveIntensity: 1.2,
})
```

不需要 Bloom，后续再加。

### **6. TransformControls 移动物体**

```typescript
const transformControls = new TransformControls(camera, renderer.domElement)
transformControls.setMode('translate')
scene.add(transformControls)

transformControls.addEventListener('dragging-changed', (event) => {
  controls.enabled = !event.value
})
```

点击圆柱后 attach：

```typescript
transformControls.attach(selectedMesh)
```

这样就能像 Godot/Blender 一样移动对象。
