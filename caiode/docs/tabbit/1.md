#### 1️⃣ **Effect 1 依赖数组膨胀**

**当前代码**:
```typescript
createEffect(on(
  () => [
    props.store.scene.cylinders,
    props.store.scene.boxes,

    props.store.scene.selectedObjectId,
```

**潜在问题**:

- 性能影响：轻微（manager 内部有 diff 和 epsilon 保护）

**优化建议**:
```typescript
// 方案 A: 拆分为两个 effect
createEffect(on(
  () => [props.store.scene.cylinders, props.store.scene.boxes, props.store.scene.lights, props.store.scene.selectedObjectId] as const,
  ([cylinders, boxes, lights, selectedId]) => {
    cylManager.update(cylinders, selectedId);
    boxManager.update(boxes, selectedId);
    lightManager.update(lights, selectedId, props.store.scene.theme());
  }
));

createEffect(on(
  () => props.store.scene.theme,
  (theme) => {
    // 仅在 theme 变化时强制刷新 light 视觉（可选）
    if (props.store.scene.lights.length > 0) {
      lightManager.update(props.store.scene.lights(), props.store.scene.selectedObjectId(), theme);
    }
  }
));
```

**严重程度**: 🟡 低（可选优化）

#### 2️⃣ **onObjectChange 分发逻辑复杂度**

**当前代码**:
```typescript
const onObjectChange = (obj: THREE.Object3D) => {
  const kind = obj.userData?.kind;
  
  if (kind === 'cylinder') {
    props.store.updateCylinder(id, { position: {...}, /* y 减 height/2 */ });
  } else if (kind === 'box') {
    props.store.updateBox(id, { position: {...} });
  } else if (kind === 'light') {
    props.store.updateLight(id, { position: {...}, rotation: {...} });
  }
};
```

**潜在问题**:
- cylinder 需要 `y - height/2` 坐标转换（store 存底面 y，mesh 存中心 y）
- box 和 light 不需要此转换
- 容易遗忘或写错

**优化建议**:
```typescript
// 在 transform-controls-setup.ts 中封装统一接口
const createObjectChangeHandler = (store: Shot3DStore) => (obj: THREE.Object3D) => {
  const id = obj.userData?.id as string | undefined;
  const kind = obj.userData?.kind as string | undefined;
  if (!id || !kind) return;

  const pos = { x: obj.position.x, y: obj.position.y, z: obj.position.z };
  
  switch (kind) {
    case 'cylinder': {
      const height = (obj.userData.height ?? 0) as number;
      store.updateCylinder(id, { position: { ...pos, y: pos.y - height / 2 } });
      break;
    }
    case 'box':
      store.updateBox(id, { position: pos });
      break;
    case 'light':
      store.updateLight(id, {
        position: pos,
        rotation: { x: obj.rotation.x, y: obj.rotation.y, z: obj.rotation.z },
      });
      break;
  }
};
```

**严重程度**: 🟡 低（代码清晰度优化）

**如果采用方案 A（单一数组）**, 应改为:
```typescript
const selectAny = (id: string | undefined) => {
  console.info('[store] selectAny called:', { prev: scene().selectedObjectId, next: id });
  setScene(prev => {
    const currentSelected = prev.selectedObjectId;
    if (currentSelected === id) return prev;

    const cylindersChanged = prev.cylinders.some(c => {
      const wasSelected = c.id === currentSelected;
      const willBeSelected = c.id === id;
      return wasSelected !== willBeSelected;
    });

    if (!cylindersChanged && currentSelected === id) return prev;

    return {
      ...prev,
      selectedObjectId: id,
      cylinders: prev.cylinders.map(c => ({
        ...c,
        selected: c.id === id
      }))
    };
  });
};
```
