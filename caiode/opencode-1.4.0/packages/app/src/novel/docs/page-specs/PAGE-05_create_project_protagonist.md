## 4. 随机姓名生成策略

内置常见中文姓氏 + 名字用字池，随机组合：
- 姓氏池：李、王、张、刘、陈、杨、赵、黄、周、吴、徐、孙、马、朱、胡、林、郭、何、高、罗
- 男性名字用字：轩、宇、辰、睿、皓、霆、霄、枫、逸、尘、墨、渊、凛、炎、煜
- 女性名字用字：瑶、琴、萱、蕊、璃、月、雪、霜、莲、茹、婉、清、灵、梦、琴
- 其他名字用字：宁、安、和、静、明、远、岚、溪
