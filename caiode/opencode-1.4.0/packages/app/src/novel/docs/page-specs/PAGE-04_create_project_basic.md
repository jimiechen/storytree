## 4. 用户流程

### 4.1 主流程：填写基本信息 → 下一步

```
[入口: 书架页"新建"按钮]
  ↓
打开 CreateProjectModal
  ↓
默认显示"基本信息"Tab
  ↓
用户填写: 小说名称(必填) / 类型 / 封面 / 目标读者 / 写作风格 / 故事主题 / 简介 / 预估章数
  ↓
点击"下一步"
  ↓
isValid() 校验 → name 非空 + genre 有效
  ├─ 校验失败 → 显示错误提示
  └─ 校验通过 → 切换到"主角设定"Tab
  ↓
[进入 PAGE-05 主角设定]
```

### 4.2 侧流程：取消创建

```
[任意 Tab]
  ↓
点击"取消" 或 遮罩层或关闭按钮
  ↓
onCancel() → 关闭弹窗 → 返回书架
```

### 4.3 侧流程：Tab 间切换

```
[任意 Tab]
  ↓
点击其他 Tab 标题
  ↓
直接切换（不校验当前 Tab）
  ↓
显示目标 Tab 内容
```

## 5. 数据模型

### 5.1 新增字段

```typescript
// types/project.ts — 新增
export interface CreateProjectInput {
  name: string;
  genre: GenreOption;
  description?: string;
  protagonist?: ProtagonistInput;
  targetAudience?: TargetAudience;
  writingStyle?: WritingStyle;
  storyTheme?: StoryTheme;
  customSettings?: string;
  estimatedChapters?: number;  // ← 新增：预估章数
  coverUrl?: string;            // ← 新增：封面图 URL（base64 或路径）
}
```

### 5.2 Tab 状态

```typescript
type CreateProjectTab =
  | 'basic'       // 基本信息（PAGE-04）
  | 'protagonist' // 主角设定（PAGE-05）
  | 'worldview'   // 世界观（PAGE-06）
  | 'plot'        // 剧情总纲（PAGE-07）
  | 'custom'      // 自定义设定（PAGE-08）
  | 'file';       // 选择文件
```

### 5.3 封面上传策略（本地持久化）

- 前端使用 `<input type="file" accept="image/*">` 选择文件
- 使用 `FileReader.readAsDataURL` 转 base64 预览
- **本地持久化**：使用 `localStorage` 存储 base64 封面图，下次打开弹窗时从本地读取显示
- localStorage key: `novel:cover:{projectId}` 或 `novel:cover:draft`（未创建项目时）
- 存储到 `coverUrl` 字段（base64 字符串）
- 限制：最大 2MB，仅接受 image/* 类型
- 可删除封面（清除 localStorage 和内存）

## 6. 实现方案

### 6.1 修改文件清单

| 文件 | 修改内容 | 行数预估 |
|------|---------|---------|
| `components/create-project-modal/index.tsx` | 重构 Tab 结构 + 新增封面/章数 + 下一步按钮 | ~400 行 |

| `types/index.ts` | 导出新类型 | +1 行 |

### 6.2 实现步骤

1. **类型扩展**：在 `CreateProjectInput` 中添加 `estimatedChapters?: number`、`coverUrl?: string`、`worldview?: string`、`plotOutline?: string`
2. **Tab 重构**：将 2-Tab（简易创作/创建新项目）改为 6-Tab（基本信息/主角设定/世界观/剧情总纲/自定义设定/选择文件）
3. **基本信息 Tab 内容**：
   - 左侧：封面上传区域（点击选择 → 预览 → 可删除，localStorage 持久化）
   - 右侧：小说名称、类型、目标读者、写作风格、故事主题、预估章数、小说简介
4. **提示文案**：在 Tab 栏下方添加提示文案
5. **主角设定 Tab**：从当前 full 模式迁移主角字段
6. **世界观 Tab**：提示词输入 + "AI 生成"按钮 → 调用 LLM 生成世界观内容 → 可编辑
7. **剧情总纲 Tab**：提示词输入 + "AI 生成"按钮 → 调用 LLM 生成剧情大纲 → 可编辑
8. **自定义设定 Tab**：从当前 full 模式迁移自定义设定字段
9. **选择文件 Tab**：文件选择 + 导入（基础实现）
10. **底部按钮（严格顺序）**：
    - 基本信息 Tab：取消 + 下一步（校验 name 非空后启用）
    - 主角设定 Tab：上一步 + 下一步
    - 世界观 Tab：上一步 + 下一步
    - 剧情总纲 Tab：上一步 + 下一步
    - 自定义设定 Tab：上一步 + 下一步
    - 选择文件 Tab：上一步 + 创建
11. **严格顺序导航**：Tab 标题仅显示当前/已完成步骤可点击，未到达的 Tab 禁用
12. **校验逻辑**：每个 Tab 的"下一步"需校验当前 Tab 必填项
