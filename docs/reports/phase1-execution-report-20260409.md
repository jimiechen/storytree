## 四、技术架构

### 4.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                    VS Code Extension                         │
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────┐  │
│  │  Webview UI     │  │  IPC Router     │  │  Config     │  │
│  │  (React/Vue)    │◄─┤  (JSON-RPC)     │◄─┤  Manager    │  │
│  └─────────────────┘  └─────────────────┘  └─────────────┘  │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Extension Core                            │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │  Preflight  │  │  Permission │  │  Worktree Manager   │  │
│  │  Checker    │  │  Manager    │  │  (Git Worktree)     │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │  SandboxFS  │  │  CDP Client │  │  Agent Config       │  │
│  │  (文件隔离)  │  │  (CDP连接)   │  │  Injector           │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                      Trae IDE                                │
│              (通过CDP协议通信)                                │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 核心模块职责

| 模块 | 职责 | 技术要点 |
|------|------|----------|
| PreflightChecker | 环境预检 | Trae可用性、Git版本、Worktree支持 |
| ConfigManager | 配置管理 | 多层配置合并、Schema验证、热更新 |
| PermissionManager | 权限控制 | 规则定义、文件/命令检查、审计日志 |
| WorktreeManager | Worktree管理 | 创建/删除/切换、残留清理、错误恢复 |
| SandboxFS | 文件系统沙箱 | 路径白名单、访问限制、虚拟文件系统 |
| CdpClient | CDP连接 | 连接封装、自动重连、状态监控 |
| AgentConfigInjector | 智能体配置 | 配置注入、验证、回滚 |
| IpcRouter | IPC路由 | JSON-RPC协议、消息路由、双向通信 |

| 风险 | 可能性 | 影响 | 缓解措施 | 责任人 |
|------|--------|------|----------|--------|

### 6.2 应急预案

| 场景 | 应急措施 |
|------|----------|
| CDP连接失败 | 1. 自动重连3次<br>2. 降级为手动模式<br>3. 通知用户检查Trae状态 |
| Worktree创建失败 | 1. 清理残留Worktree<br>2. 使用备用路径<br>3. 通知用户检查磁盘空间 |
| 智能体注入失败 | 1. 回滚配置<br>2. 使用默认配置<br>3. 记录错误日志 |
| 沙箱验证失败 | 1. 拒绝启动智能体<br>2. 通知用户检查权限<br>3. 提供修复指南 |
