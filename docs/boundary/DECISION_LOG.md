### D-003: 富文本数据格式

**提案人**: 项目主控  
**决策人**: 项目主控  
**提案时间**: 2026-05-31  
**决策时间**: **2026-05-31**  
**状态**: **Approved**

#### 背景

章节编辑器的富文本格式选择，影响：
- 导入导出协议
- 云同步策略

| TipTap JSON | HTML | Markdown |

#### 影响

- 需要在 shared-schema 中定义 TipTap JSON Schema
- 需要实现双向转换器
- 影响 novel 模块的编辑器选型

#### 批复

```
✅ 批准: TipTap JSON 作为主要格式，Markdown 作为导出格式。
原因:
1. TipTap JSON 支持丰富的格式控制
2. Markdown 是行业标准导出格式
3. 双向转换器实现成本可控
```

### D-005: 用户隐私与训练数据边界

**提案人**: 项目主控  
**决策人**: 项目主控  
**提案时间**: 2026-05-31  
**决策时间**: **2026-05-31**  
**状态**: **Approved**

#### 背景

用户小说内容属于敏感数据，必须明确：
- 是否用于模型训练
- 数据存储位置
- 云同步安全性

#### 决策

| 原则 | 内容 |
|------|------|
| **隐私优先** | 用户小说内容默认本地存储，不上传服务器 |
| **禁止训练** | 用户内容不用于任何模型训练 |
| **云同步加密** | VIP 云同步走端到端加密 |
| **数据主权** | 用户可随时导出/删除自己的数据 |

#### 影响

- 影响 server-billing 包的云同步设计
- 影响隐私政策文档
- 需要实现端到端加密

#### 批复

```
✅ 批准: 严格隐私保护原则
1. 所有用户内容默认本地存储
2. 不回传训练数据
3. 云同步仅对 VIP 开放，且必须端到端加密
4. 用户可随时导出/删除数据
```

#### 变更记录

- 2026-05-31: 批准此决策
