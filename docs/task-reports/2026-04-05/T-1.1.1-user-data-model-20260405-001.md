## 数据模型概览

### User 模型
- id: UUID (主键)
- email: 唯一邮箱
- passwordHash: 密码哈希
- nickname: 昵称
- avatarUrl: 头像URL
- subscriptionTier: 订阅等级 (free/pro/enterprise)
- createdAt/updatedAt: 时间戳

### UserPreferences 模型
- id: UUID (主键)
- userId: 外键 (唯一)
- uiLanguage: 界面语言 (默认 zh)
- writingLanguage: 写作语言 (默认 zh)
- timezone: 时区 (默认 Asia/Shanghai)
- currency: 货币 (默认 CNY)
- region: 区域 (默认 ap)

### Subscription 模型
- id: UUID (主键)
- userId: 外键 (唯一)
- plan: 订阅计划 (free/pro/studio/team)
- status: 订阅状态
- stripeCustomerId: Stripe 客户ID
- stripeSubscriptionId: Stripe 订阅ID
- currentPeriodStart/End: 计费周期
- cancelAtPeriodEnd: 是否周期结束取消
