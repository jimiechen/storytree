## 功能特性

### 角色表单字段
- **基本信息**: 名称(必填)、别名、年龄、性别、职业
- **详细设定**: 外貌描述、性格特点、背景故事、目标/动机
- **标签管理**: 支持添加/删除多个标签

### CRUD 操作
- **Create**: 点击"新建角色"按钮，填写表单，保存
- **Read**: 角色卡片列表展示，支持搜索过滤
- **Update**: 点击角色卡片菜单，选择"编辑"，修改后保存
- **Delete**: 点击角色卡片菜单，选择"删除"，或在编辑表单中删除

### 交互设计
- 弹窗式表单，支持滚动
- 表单验证（名称必填）
- 别名和标签的动态添加/删除
- 角色卡片下拉菜单（编辑/删除）
- 搜索支持名称和别名

## 经验总结
1. 使用 Modal 弹窗而非 Drawer，更适合表单较多的场景
2. 表单组件设计为受控组件，便于数据管理和验证
3. 别名和标签使用动态数组管理，提供良好的用户体验
4. 下拉菜单使用绝对定位，点击外部自动关闭
5. E2E 测试覆盖完整的用户操作流程
