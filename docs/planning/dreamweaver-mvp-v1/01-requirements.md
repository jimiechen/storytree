# 项目需求文档 (PRD)

> **迭代版本**: dreamweaver-mvp-v1
> **目标**: 搭建基础工程和 Playwright 自动化验收工程，完成核心写作工作台基础功能

---

## 1. 项目概述

### 1.1 背景
DreamWeaver 是一款面向全球长篇小说创作者的 AI 原生创作平台。MVP 版本聚焦于核心写作体验验证，搭建基础工程架构和自动化测试体系。

### 1.2 目标
搭建可运行的基础工程，包含：
1. Next.js + TypeScript 基础工程
2. Playwright 自动化验收测试工程
3. 核心写作工作台（编辑器 + AI 对话面板）
4. 基础项目管理功能

### 1.3 目标用户
- **网文日更作者**: 需要高效的 AI 辅助写作工具
- **类型小说新人**: 需要世界观管理和一致性检查

## 2. 详细功能设计

### 2.1 模块 A: 写作工作台 (Writing Workbench)

#### 2.1.1 页面: 写作工作台
**路径**: `/workbench`

**UI 元素清单**:

| 元素名称 | 类型 | 验证规则 | 默认值 | 交互逻辑 | 异常处理 | 权限 |
|---|---|---|---|---|---|---|
| 编辑器区域 | TextArea | 必填 | 空 | 支持富文本编辑、自动保存 | 显示保存失败提示 | 登录用户 |
| AI 对话面板 | ChatPanel | - | 折叠 | 点击展开/折叠，支持多轮对话 | 显示连接错误 | 登录用户 |
| 章节导航 | Sidebar | - | 展开 | 点击切换章节，支持新建章节 | - | 登录用户 |
| 字数统计 | StatDisplay | - | 0 | 实时统计字数 | - | 登录用户 |
| 保存按钮 | Button | - | - | 点击手动保存，显示保存状态 | Toast 提示保存结果 | 登录用户 |

**逻辑流程**:
1. 用户进入工作台，加载最近编辑的项目
2. 编辑器支持富文本编辑（加粗、斜体、标题等基础格式）
3. 内容变更后自动触发保存（防抖 2 秒）
4. AI 对话面板支持展开/折叠，可发送消息获取 AI 建议
5. 章节导航支持创建新章节、切换章节

## 3. 非功能需求

### 3.1 性能
- 页面首屏加载 < 2s
- AI 响应时间 < 3s（简单任务）
- 编辑器输入延迟 < 50ms

### 3.2 安全
- 用户密码 bcrypt 加密存储
- JWT Token 认证
- API 请求速率限制

### 3.3 兼容性
- 支持 Chrome, Firefox, Safari 最新版本
- 响应式布局（桌面端优先）

### 3.4 可维护性
- 代码遵循 TypeScript 严格模式
- 组件需包含单元测试
- E2E 测试覆盖核心流程

---

## 4. 假设与约束

### 4.1 假设
- AI 模型 API（Claude, GPT-4o）可用且稳定
- 用户使用现代浏览器

### 4.2 约束
- MVP 版本暂不支持移动端
- 暂不支持离线编辑
- AI 功能需要联网
